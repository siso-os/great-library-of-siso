What it's for (first principles)

The Estate and the Library, one place

  1. One rail icon, "Estate". Inside it, a switch between World (the 3D land) and Library (the building). The separate Library icon is retired.
  2. Walk in from the map. Clicking the Library building in the World opens the Library, and clicking a project's building opens its Projects page.
  3. The register stays with the land. The old Built and Live lists go under World as "Register", because they're where-things-are data.
  1. One build, two homes, the same as the Estate. The Library builds into one static folder. Agent Base shows it at /library-site/, and a private Cloudflare Worker serves it to your phone behind the Estate's password.
  2. Fresh by itself. A rebuild every hour picks up new pages and docs. Nothing is copied by hand.
  3. Private stays private. Life, WhatsApp, Fahmy, personal/ and anything that looks like a key never leave the laptop build.

Cleaning up the docs

  • Fold duplicates. Identical files fold into one, wherever they sit. The same page posted many times becomes one page with its versions.
  • Archive what's dead. I'll read the Library's own 39 docs and archive the superseded ones (the four earlier UI specs, among others) under _archive/. Nothing gets deleted.
  • Hide the plumbing. Releases, Snapshots and Promotion leave the main nav. They stay reachable for agents.
