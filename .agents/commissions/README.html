Commissions

A commission is a research question given to a frontier model on a long-running, budgeted lane. It is not a task. Tasks live in .agents/tasks/ in the repo that owns the work, and are executed by ordinary agents. A commission is for a question where being wrong is expensive and being right compounds.

The admission filter

Three tests. All three must pass, or it is a task, not a commission.

TestWhy
Would a merely-good agent get this materially wrong? If a competent Opus lane produces the same answer, spend the Opus lane. Frontier capacity is the scarce resource; implementation is not where it wins.
Is the answer durable? Still true in six months. A benchmark, an architecture, a rights model — yes. A merge, a CI fix, a red build — no.
Does it unblock other work? Terminal answers are worth less than answers that release a queue behind them.

What is explicitly NOT a commission

  • Writing code from an existing spec — Opus lanes did the whole of 2026-08-07/08 fine.
  • Merging, CI repair, dependency bumps, schema edits with a known shape.
  • Anything already specified in parallel-slam.md or the superseded pack — those are executable, not researchable.

Why this file exists — the lesson it encodes

Measured across 2026-08-07/08: seven separate times something reported success while doing nothing. A test that failed to import. A delete loop silently no-op'd by a grep filter. A validator whose EXPECTED_TABLES never required the 4 missing tables. A meta_json LIKE '%key%' counter matching values as keys. An FTS query that raised no such column and fell back to a scan. Every one was caught by an outside reader or by measurement — never by the author's own tests.

Fixtures encode what you already believed. So every commission must state, up front, what would make it wrong — and a deliverable that cannot be falsified is rejected on arrival, however plausible it reads.

Commission file contract

One HTML per commission, named C-NNNN-slug.html. Required sections:

SectionContent
QUESTIONOne sentence. The thing we do not know.
WHY FRONTIERWhich of the three admission tests it passes, and how.
RECEIPTSThe measured facts it starts from, each with its source. No commission starts from an assumption.
FALSIFIERSWhat result would prove the answer wrong. Mandatory.
DELIVERABLEExact artifact shape and where it lands.
BUDGETHard ceiling. A commission that overruns reports and stops.
NOT IN SCOPEWhat it must not drift into.
STATUSdrafted / commissioned / returned / accepted / rejected

Returned ≠ accepted. A returned commission gets read adversarially before it is accepted, by someone who did not write it. That gate is the entire reason GQ-009 watch-trigger 5 is recorded as partially fired and not fired: 16 of 17 librarian proposals survived independent review, but a Claude reviewed a Claude — mechanically independent, not a different mind with different blind spots.
